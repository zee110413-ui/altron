# Field test reports / Отчёты полевых тестов

`brain/field_test.py` writes a report here after a run in the real game: what Altron's own legs managed on the test
course, what the AI said and did in each talk, events of the world, errors from the brain and the game logs.
Push a report on a branch of its own (the commands are printed at the end of the run) for it to be read.

`brain/field_test.py` кладёт сюда отчёт после прогона в игре. Отправляй его в отдельной ветке — команды печатаются
в конце прогона.
